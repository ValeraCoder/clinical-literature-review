# Карточка источника

| Поле | Что записать |
| --- | --- |
| Ссылка | Авторы, год, название, DOI / PMID / официальный URL |
| Версия и доступ | Редакция, дата проверки, полный текст / фрагмент / аннотация |
| Исследование | Дизайн, номер регистрации и связанные публикации |
| Выборка | Критерии, число участников, способ набора |
| Сравнение | Вмешательство и контроль или сравниваемые группы |
| Исход | Что измеряли, чем и когда |
| Результат | Оценка эффекта с единицами, знаменателем и интервалом, если они доступны |
| Локатор | Страница, таблица, рисунок, раздел или приложение |
| Ограничения | Выбывание, риск смещения, применимость к нужной группе |
| Допустимый вывод | Одно утверждение, которое поддерживает проверенный фрагмент |

Для руководства вместо выборки запишите организацию, целевую группу, номер рекомендации и редакцию.
