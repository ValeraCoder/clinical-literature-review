# Как предложить правку

Откройте issue с указанием обзора, конкретного утверждения и источника, по которому можно проверить правку. Для статьи укажите DOI или PMID, раздел или таблицу и редакцию текста. Уточните, если доступна только аннотация.

Если предлагаете новый обзор, сформулируйте вопрос и приложите один или два релевантных первоисточника. Для готовой правки откройте pull request, кратко опишите изменение и обновите дату проверки материала. Пользуйтесь [методикой](docs/methodology.md) и [правилами общения](CODE_OF_CONDUCT.md).

Issues и pull requests могут быть видны всем. Добавляйте только публичные сведения и материалы, на размещение которых у вас есть право. Для сообщений о конфиденциальности используйте личный контакт автора. [Telegram](https://t.me/yahochushaslik)
