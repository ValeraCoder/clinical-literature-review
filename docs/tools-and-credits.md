# Какие инструменты я использовал

Когда я настраивал Research, мне хотелось разнести по шагам работу, которая в чате легко сливается в один ответ. Найти статью, прочитать её и решить, насколько она отвечает на мой вопрос, — разные задачи. Для каждого шага я собрал инструкции для агента, посмотрел, как они работают на примерах, и оставил те, которые помогали проверять выводы. Это и есть настройка Research. Модель я не дообучал.

## Поиск, обзор и чтение статьи

| Что подключал | Для чего |
| --- | --- |
| **Research** | Ведёт вопрос, поиск и общий журнал. Если я возвращаюсь к теме и прошу уточнить вывод, агент поднимает результаты того же поиска и проверяет только то, чего не хватало. В этом репозитории есть самостоятельная инструкция для Codex. [Research Literature](../.agents/skills/research-literature/SKILL.md) |
| **Deep Research** | Помогает разложить обзор на вопросы, распределить чтение и проверить, выдерживает ли вывод сравнение с другими работами. В обзоре по СДВГ я использовал локальную адаптацию инструкций Cheng-I Wu. [Deep Research, исходный проект](https://github.com/Imbad0202/academic-research-skills/tree/060cb3cbffc2ca1bdfb8f7c6d2ffa4883cf09b1a/deep-research) |
| **Scientific Thinking Literature Review** | Из набора ECC я взял отдельную инструкцию для отбора статей, таблицы доказательств и проверки ссылок. Она была доступна в рабочей среде и участвовала в проверке порядка работы. [ECC](https://github.com/affaan-m/ECC) |
| **Nature Paper X-Ray** | Подключал для чтения конкретной работы. Здесь важны методы, таблицы и приложения. Например, в пакете по взрослому СДВГ я сверял описания упражнений с опубликованными процедурами. [Nature Skills](https://github.com/yuan1z0825/nature-skills/tree/f8797feed6405035e7d57f59cb8ba393c6a98802) |
| **Google Scholar Search** | Дополнительный поиск по запросу. При настройке я проверил, что браузер открывает Scholar, но выдачу остановила CAPTCHA. В [семиязычный обзор по СДВГ](../reviews/adult-adhd-occupational-therapy/search-log.md) результаты Scholar не вошли. [GS Skills](https://github.com/cookjohn/gs-skills/tree/df03c99f1a741ff816e6f0e12c13308279bcd730/skills/gs-search) |

В Nature Skills есть отдельный **Nature Paper Trans** для перевода английской статьи на китайский в виде PDF с похожим макетом. Я проверял подготовку страниц для этого режима. В обычном поиске и русском переводе этот инструмент не использовался. [Nature Skills](https://github.com/yuan1z0825/nature-skills/tree/f8797feed6405035e7d57f59cb8ba393c6a98802)

## Психометрия и расчёты

Когда я проверял рабочий бланк по биполярному спектру, мне нужно было выяснить, что именно измеряет каждый блок, за какой период и на какой выборке проверяли пороги. Для этой задачи я собрал отдельную инструкцию по клинической психометрии. Она использует результаты уже проведённого поиска и задаёт порядок сверки с руководствами и исследованиями шкал.

| Что подключал | Для чего |
| --- | --- |
| **MedSci Skills / Check Reporting** | Сверял, что авторы сообщили о выборке, референтном стандарте и точности шкалы. Для оценки полноты отчёта об исследовании диагностической точности использовал ориентиры STARD, для оценки методики изучения свойств измерения — критерии COSMIN. [MedSci Skills](https://github.com/Aperivue/medsci-skills/tree/cc462bc2069064b557c2fea12a1f83ed1fe67f66/skills/check-reporting) |
| **K-Dense / Scientific Critical Thinking** | Использовал для проверки дизайна, возможных смещений и применимости выводов к нужной группе. [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills/tree/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/scientific-critical-thinking) |
| **statsmodels** | Подключил для статистических расчётов, например интервалов Уилсона, когда в статье есть исходные числа. [statsmodels](https://github.com/statsmodels/statsmodels) |
| **Pingouin** | Подключил для анализа надёжности, когда есть ответы по отдельным пунктам или оценки нескольких наблюдателей. [Pingouin](https://github.com/raphaelvallat/pingouin) |

Расчётные библиотеки я проверил на синтетических данных. Проверка показала, что формулы и инструменты работают на этих примерах. Для клинической валидации нужны данные отдельного исследования.

Инструменты выше описывают рабочую среду, в которой вырос Research. Читать обзоры, вести свой [журнал поиска](../templates/search-log.md) и пользоваться [методикой](methodology.md) можно прямо из репозитория.
